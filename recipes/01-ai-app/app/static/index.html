What's really going on

  1. Knock firstA shared token has to match, or you're turned away at the door.
  2. Mind the limitsBody size, request rate, concurrency, response size, a hard deadline.
  3. Fail on purposeTidy errors — no leaking the provider's response or your secrets.
  4. Leave a trailHealth checks and request IDs, with zero prompt logging.

Prove it yourself 🔍

The dull reply isn't the point — surviving these checks is. Each button sends one deliberately broken request and shows how the app stops it.

Paste your app token in the box above ↑ to unlock checks 3–8, then press any run.

  1. 1No token

    I send: a request with no token.

    — press run —

    Lesson: a stranger can't reach your model or spend your budget.

    how it's done
    supplied = request.headers.get("authorization", "").encode()
expected = f"Bearer {app_token}".encode()
if not hmac.compare_digest(supplied, expected):
    raise HTTPException(401, "Valid bearer token required")
  2. 2Wrong token

    I send: a made-up bearer token.

    — press run —

    Lesson: a leaked or guessed key still gets nothing (compared in constant time).

    how it's done
    # hmac.compare_digest avoids timing leaks that
# would let an attacker guess the token byte by byte
if not hmac.compare_digest(supplied, expected):
    raise HTTPException(401, "Valid bearer token required")
  3. 3Wrong content-type

    I send: valid token, but Content-Type: text/plain.

    — press run —

    Lesson: the app processes only what it declared it accepts (JSON).

    how it's done
    ct = request.headers.get("content-type", "").split(";", 1)[0]
if ct.strip().lower() != "application/json":
    raise HTTPException(415, "Use application/json")
  4. 4Over-long message

    I send: a 5,000-character message (limit is 4,000).

    — press run —

    Lesson: refused before any model call, so a giant prompt can't run up cost.

    how it's done
    class ChatInput(BaseModel):
    model_config = ConfigDict(extra="forbid")
    message: StrictStr = Field(min_length=1, max_length=4000)
  5. 5Oversized body

    I send: a ~20 KB raw body (limit is 16 KB).

    — press run —

    Lesson: dropped before JSON is even parsed — protects memory.

    how it's done
    size += len(chunk)              # MAX_BODY = 16_384
if size > MAX_BODY:
    return await reject(413, "Request body too large")
  6. 6Smuggled field

    I send: an unexpected "admin": true field.

    — press run —

    Lesson: a strict schema rejects extra fields instead of trusting them.

    how it's done
    # extra="forbid" rejects any field that isn't "message"
class ChatInput(BaseModel):
    model_config = ConfigDict(extra="forbid")
  7. 7Flood it

    I send: 35 requests fast (budget is 30/min). spends the shared minute — chat may answer 429 for ~60s.

    — press run —

    Lesson: one caller can't swamp the service.

    how it's done
    if app.state.requests >= requests_per_minute:   # 30
    raise HTTPException(429, "Local request limit reached",
                        headers={"Retry-After": retry})
  8. 8Response headers

    I send: a normal request — then inspect what came back.

    — press run —

    Lesson: hardened headers (CSP, nosniff, no-referrer) + a request ID to trace the call.

    how it's done
    message["headers"] += [
    (b"x-request-id", request_id.encode()),
    (b"content-security-policy", b"default-src 'self'; ..."),
    (b"x-content-type-options", b"nosniff"), ...]
