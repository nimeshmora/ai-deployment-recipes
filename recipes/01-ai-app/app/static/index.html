What protects this deployment

  1. Authentication requiredOWASP API2

    A request with no token never reaches the model — anonymous traffic can't spend your budget.

    show the code
    supplied = request.headers.get("authorization", "").encode()
expected = f"Bearer {app_token}".encode()
if not hmac.compare_digest(supplied, expected):
    raise HTTPException(401, "Valid bearer token required")
  2. Rate limitedOWASP LLM10

    One caller can't flood the service. Over the budget (30/min), extra requests get 429. This test spends the shared minute — the chat may answer 429 for ~60s.

    show the code
    if app.state.requests >= requests_per_minute:   # 30
    raise HTTPException(429, "Local request limit reached",
                        headers={"Retry-After": retry})
  3. Oversized requests blockedOWASP LLM10

    A huge payload is dropped before it's even parsed, protecting memory (limit 16 KB).

    show the code
    size += len(chunk)              # MAX_BODY = 16_384
if size > MAX_BODY:
    return await reject(413, "Request body too large")
  4. Hardened response headersOWASP API8

    Every response carries CSP, nosniff, no-referrer, no-store, and a request ID you can trace in logs.

    show the code
    message["headers"] += [
    (b"x-request-id", request_id.encode()),
    (b"content-security-policy", b"default-src 'self'; ..."),
    (b"x-content-type-options", b"nosniff"), ...]
  5. Timeout + no hidden retriesOWASP LLM10built in

    Every model call has a hard deadline, so a slow provider never hangs the service — and nothing is silently retried behind your back.

    show the code
    # one overall deadline; no automatic retries anywhere
async with asyncio.timeout(settings.deadline_seconds):
    ... call the model once ...
  6. Logs never record your dataOWASP LLM02built in

    Prompts, answers, and tokens are never written to logs — only a status, a duration, and a request ID. Verify with docker compose logs app.

    show the code
    # intentionally excludes prompts, answers, credentials, URLs
LOG.info(json.dumps({"event": "http_request",
    "request_id": request_id, "status": status,
    "duration_ms": duration}))
  7. Locked-down containerOWASP API8built in

    Runs as a non-root user on a read-only filesystem, with Linux capabilities dropped and memory/CPU limits — so a compromise has little room to move.

    show the code
    # compose.yaml
read_only: true
cap_drop: [ALL]
security_opt: ["no-new-privileges:true"]
mem_limit: 256m
# Dockerfile runs as UID 10001, not root
