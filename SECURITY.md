# Security

This is an early educational/reference project, not a security-certified platform. Read the deployment scope before exposing any recipe to untrusted traffic.

Never include credentials, real personal data, or exploit payloads against live third-party systems in public issues. For a suspected vulnerability, use GitHub's private vulnerability reporting if the repository owner has enabled it. If unavailable, ask the maintainer for a private reporting channel without posting sensitive details. No private channel or response SLA is claimed by this file.

Maintainer release checklist: enable private vulnerability reporting, keep dependency updates enabled, inspect advisory results, scan the final container, test live integrations, and rotate any credential exposed accidentally. See `docs/publishing.md`.
